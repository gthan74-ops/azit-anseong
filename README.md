# 아지트 안성 (AZIT ANSEONG)

안성의 재료와 사람을 브랜드로 만들고, 콘텐츠로 알리고, 함께 키우는 로컬 비즈니스 스튜디오의 공식 웹사이트입니다.
첫 제품 프로젝트 **황금배소금**(안성 배 요리소금)을 함께 소개합니다.

- 공개 주소: https://gthan74-ops.github.io/azit-anseong/
- 구성: 순수 정적 사이트 (HTML · CSS · JS), GitHub Pages 배포
- 구조
  - `index.html` — 페이지 본문
  - `style.css` — 디자인 (반응형)
  - `app.js` — 메뉴, 스크롤 등장 효과, 영상 재생 제어
  - `assets/` — 제품·시식회 사진(웹 최적화), 콘셉트 이미지, 영상

사진과 영상의 저작권은 아지트 안성에 있습니다.
